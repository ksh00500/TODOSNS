# Android · 파스텔과 기록 중심의 화면

2026-10-24 (Asia/Seoul). 사용자 승인 방향: 기존 규격에서 벗어나더라도 차분한 라이프스타일 매거진처럼 고도화하고 연노랑·연하늘·연초록 파스텔을 사용한다. Android에서 기존 Cloud Rhythm의 시각 토큰/배치를 아래와 같이 발전시킨다. 웹의 기존 색상 구현은 이번에 변경하지 않는다. 접근성·5탭·상태/데이터 계약은 계속 적용한다.

## 팔레트

| 역할 | 색 | 사용 |
| --- | --- | --- |
| 연하늘 Sky | `#DDEFF7` | 큰 주 행동, 선택된 탭, 기록 진입 |
| 연초록 Meadow | `#DFEEDB` | 완료한 항목, 차분한 실천·그룹 정보 |
| 연노랑 Butter | `#FFF1C7` | 확인된 성취, 등급, 사진 없는 완료 기록 |
| 아이보리 | `#FCFAF5` | 전체 바탕과 여백 |
| 본문 | `#25343B` | 파스텔 위의 제목·숫자·주 행동 글자 |
| 보조 글자 | `#56666D` | 설명·날짜·분류 |
| 짙은 블루 | `#315F73` | 링크·아이콘·포커스·진행 막대, 짙은 소형 행동 |
| 조작 경계 | `#6A818C` | 연하늘 버튼·입력의 경계. 비조작 카드 구분선보다 선명하게 유지 |

아이보리/흰색과 여백을 가장 넓게 사용하고 파스텔은 의미 있는 구역에 둔다. 세 색을 사용할 수 있으나 넓은 색면은 하나를 중심으로 하고 나머지는 작은 강조에 사용한다. 색만으로 완료·오류·선택을 전달하지 않는다. 오류·삭제의 빨강은 별도 의미색으로 유지한다.

파스텔 위에는 짙은 글자를 사용한다. 흰 글자는 짙은 블루 등 충분한 대비가 있는 배경에만 사용한다. 파스텔 큰 버튼에는 짙은 경계·글자를 함께 사용하며 최소52dp 높이를 유지한다. 수치 대비 검사와 실제 기기 캡처를 구분한다.

## 화면 적용

| 화면 | 방향 |
| --- | --- |
| 오늘 | 진행 요약을 여백과 막대로 표현하고 현재 실천은 큰 제목·연하늘 색면으로 구분. 나머지 목록은 낮은 강조, 모두 완료가 확인되면 연노랑 안내 |
| 탐색·게시물 | 작성자→사진 또는 텍스트 기록→분류/본문→반응→가져오기 순서. 사진은 넓게, 사진 없는 기록은 높이가 늘어나는 연노랑 글 영역. 고정 사진 비율에 긴 글을 끼워 넣지 않음 |
| 마이 | 작은 아바타와 이름·소개·텍스트 수치, 바로 이어지는 완료 기록 진입. 등급은 연노랑 보조 카드. 통계의 큰 아이콘과 반복 장식을 줄여 개인 기록이 먼저 읽히게 함 |
| 공통 | 선택된 탭 연하늘, 주 행동 짙은 글자/연하늘, 일반 정보와 조작 경계 분리. 둥근 정도는 용도에 따라14/20/26dp |

긴 제목·닉네임·태그는 줄바꿈하고 작은 모서리와 안쪽 여백으로 글자가 잘리지 않게 한다. 실제 사진이 없으면 다른 사진이나 예시 데이터를 대신 넣지 않는다. 사진 로딩 실패·재시도, 작성/가져오기 초안·불확실 결과, 계정/권한 상태를 스타일 변경과 함께 제거하지 않는다.

기존 Android 코드의 `Lavender/Aqua/Blush` 참조는 각각 새 Sky/Meadow/Butter 역할의 호환 별칭이다. 사용자 카테고리의 `aqua/blush/butter/lilac` 저장 값과 그 색상은 기존 의미를 유지하고 브랜드 토큰과 분리한다. 서버 자료를 새 색상 코드로 덮어쓰지 않는다.

정상·긴 글·큰 글자·빈 상태·오류의 실제 실행/시각 결과와 후속 범위는 [파스텔 구현 보고서](../redesign/android-v1/implementation-pastel.md)에 기록한다. 이 문서는 전체 화면 디자인/실기기/출시 검수 완료를 의미하지 않는다.
