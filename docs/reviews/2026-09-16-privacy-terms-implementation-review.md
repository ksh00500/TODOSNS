# 개인정보 처리방침·이용약관 구현 대조 초안

상태: 코드 대조 결과와 법률 검토용 작성 재료. 확정 법률 문안이나 운영 승인 문서가 아니다.

## 코드에서 확인한 처리 범위

- 계정: 이메일, 비밀번호 해시 또는 Google 식별자, 닉네임, 핸들, 생년월일, 시간대, 프로필·관심사, 이메일 인증 상태를 처리한다. 세션에는 user-agent와 해시 처리된 IP 식별값을 둘 수 있다.
- 사용자 콘텐츠: TODO·반복·그룹·카테고리, 게시물·댓글·응원·팔로우·차단·신고, 챌린지 참여·인증·투표, 1:1 및 챌린지 메시지·반응·수정 이력·읽음 위치를 처리한다.
- 미디어: 프로필, 게시, 사진 인증, 대화 첨부의 원본·썸네일과 파일명·MIME·크기·가로세로 값을 객체 스토리지와 DB에서 처리한다.
- 공개 범위: TODO·그룹·게시물의 `PRIVATE/FOLLOWERS/PUBLIC`, 공개 프로필과 챌린지 참여 맥락이 있다. 차단은 양방향 노출과 변경 동작에 영향을 준다.
- 분석: `ANALYTICS_COLLECTION_ENABLED`와 export 승인 스위치가 꺼져 있으면 수집·반출을 거부하고, 탈퇴·정지 계정은 새 분석 수집 대상에서 제외한다. 실제 운영 활성화 여부와 수집 이벤트 목록은 별도 확인이 필요하다.
- 파기: 탈퇴 요청 즉시 세션을 폐기하고 파기 작업을 등록하며, worker가 소유 미디어와 사용자를 제거한다. 공동 대화·신고·감사 기록의 관계별 보존/익명화와 backup 재삭제 기간은 아직 정책 확정이 필요하다.

## 개인정보 처리방침 수정 목록

1. 개인정보처리자 명칭·대표자/담당자·연락처·주소, 적용일과 변경 고지 방식을 운영자가 확정한다.
2. 수집 항목을 필수/선택/자동 생성으로 나누고 Google 로그인, 접속 기록, 미디어 메타데이터, 메시지·차단·신고·챌린지 검수 자료를 누락 없이 적는다.
3. 각 처리 목적과 법적 근거, 보유 기간을 법률 검토로 확정한다. 현재 코드의 즉시 파기 시도와 보안 토큰 7일 정리는 근거 자료일 뿐 법정 보관 기간을 대신하지 않는다.
4. 공개 범위별 노출 대상, 사진 인증이 참여자 검수자에게 보이는 범위, 신고 시 메시지 앞뒤 문맥과 수정 이력이 운영자에게 열리는 범위를 설명한다.
5. 객체 스토리지·이메일·Google 인증·호스팅 등 실제 수탁자/국외 이전 여부는 배포 구성을 확인한 뒤 업체명·국가·항목·목적·기간·거부 영향을 채운다.
6. 탈퇴 즉시 접근 차단, 비동기 원본 삭제, 공동 기록과 감사 기록, backup 복원 시 재삭제 절차를 구분한다. 미확정 예외를 무기한 보유로 표현하지 않는다.
7. 열람·정정·삭제·처리정지·동의 철회와 이의 제기 경로, 미성년자 정책을 실제 운영 절차와 맞춘다.

## 이용약관 수정 목록

1. 서비스 주체·연락처·적용일, 가입·계정 보안·초대형 베타·연령 조건을 확정한다.
2. 사용자 콘텐츠 권리와 서비스 내 표시 범위, 공개 게시물의 TODO 가져오기, 사진 인증·신고 검수에 필요한 제한적 이용 범위를 설명하되 과도한 권리 양도를 두지 않는다.
3. 1:1/챌린지 대화, 차단 뒤 기록 보존과 변경 거부, 신고·숨김·채팅 제한·계정 정지 기준 및 이의 제기 절차를 포함한다.
4. 포인트·등급·챌린지 보상은 금전 가치나 지급 보장을 임의로 약속하지 않고 실제 운영 규칙과 중단·오류 처리 기준을 맞춘다.
5. 계정 탈퇴, 콘텐츠 삭제의 차이, 공동 기록·법정 보관·backup 처리와 서비스 변경·중단·책임 제한은 관할 법률 검토 후 확정한다.

현재 `/privacy`와 `/terms` 페이지는 위 범위를 일부만 언급하는 자리표시자다. 운영자 정보, 법적 근거, 보관 기간, 수탁자와 관할을 확정하기 전에는 “검토 완료”로 표시하지 않는다.
