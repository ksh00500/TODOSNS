## 실제 브라우저 회귀 결과

- 프레임: 360×800, 390×844, 430×932, 600×800, 1280×600에서 앱 폭 최대 430px, 가로 넘침 0, 하단 메뉴 도달 가능.
- 낮은 폼: 360×400에서 `.app-scroll` 높이 400/스크롤 높이 1824, 최대 스크롤 시 CTA와 앞 콘텐츠 사이 28px, 입력 겹침 없음. 이는 축소 viewport 검증이며 실제 모바일 키보드 실기기 검증은 아니다.
- 시트: 메시지 메뉴 전환, 반복 종료 중첩, 사진 검수 중 신고 중첩에서 최상위 Esc, 잠금 유지/최종 해제, 포커스 복귀 확인.
- 입력: 날짜 선택 후 날짜 트리거, 시간 적용 후 시간 트리거 복귀. 선택 시간 자동 노출과 방향키 변경 확인.
- 가져오기: 제목·시간·반복을 편집한 뒤 모드 왕복해도 유지.
- 채팅: 44px 타깃, 가로 넘침 0, 챌린지 방 ID 전환 시 이전 방 신규 상태가 남지 않음.
- 탐색: 기존 `type=tags` 직접 URL에서도 통합 버튼이 선택되고 태그 카드 아래 관련 게시물이 즉시 노출됨. 표준 버튼 그룹과 `aria-pressed`가 접근성 트리에 반영됨.
- 대비: 해시태그 lilac 면과 완료 TODO aqua 면의 보조 글자가 실제 `rgb(85,79,92)`, 13px로 계산됨.
- 사진 검수: 확대 시 부모/자식 dialog 2개와 body 잠금을 유지하고, Esc는 확대 시트만 닫은 뒤 `인증 사진 크게 보기` 버튼으로 포커스를 복귀함.
- 마이: `조각구름 등급 상세 보기` 링크가 `/me/rank`로 이동하고, 현재 186 뭉실·다음 등급까지 114 뭉실·전체 6단계와 적립 기준을 렌더함. `.app-scroll` 428px에서 가로 넘침 0.
- 배지: 시스템 배지 3개와 챌린지 배지 1개가 모두 버튼으로 노출됨. `맑은 아침 구름` 시트에서 만든 곳, 최종 1위 기록, 관련 챌린지와 상세 링크를 확인하고 Esc 포커스 복귀를 확인함.
- 연결: `/people/mongsil.day/connections?type=followers`의 초기 404를 재현한 뒤 생성된 `.next/dev` 캐시를 재생성했다. 재시작 후 팔로워·팔로잉 전환과 사용자 3명 목록, HTTP 200을 확인함.
- 탐색·검색: 검색 화면 접근성 트리에서 뒤로가기 `탐색`, 보조 문구 `실천 찾기`, 화면 제목 `검색`의 위계를 확인함.
- 챌린지 CTA: 두 52px 버튼 사이의 계산된 실제 간격 12px, `.app-scroll` 가로 넘침 0을 확인함.

## 실행하지 못한 검증

- 실제 200% 브라우저 확대: 현재 인앱 브라우저가 확대 단축키를 반영하지 않았다.
- 모바일 키보드·스크린리더·축소 모션: 실기기/보조기술 환경이 없다.
- 실제 API 오류 주입, 오프라인 복구, 토큰 만료, READY 미디어 재시도: 로컬 체험 서버는 운영 백엔드·스토리지 실패를 재현하지 않는다.
- 실제 DB 핵심 순환과 다계정 소켓/차단/읽음/관리자 E2E: 테스트 계정과 실행 중인 로컬 API·DB가 없다. API 테스트의 핵심 순환 1건도 같은 이유로 스킵됐다.
