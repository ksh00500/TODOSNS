## 운영 정보·정책 결정 대기

- 운영 주체·연락처, 실제 도메인, SMTP/발신 도메인, 학교 프록시·허용 포트
- 개인정보·신고 증거·감사 로그·백업의 보유 기간
- 탈퇴한 방장 표시명 익명화 및 진행 중 챌린지 소유권 이전 규칙
- 공개 게시물을 게시 시점 스냅샷으로 보존할지 원본 변경을 반영할지

임의 값으로 확정하지 않고 코드 안전장치를 먼저 구현한 뒤 `외부 확인 필요`로 남긴다.

## 검증 기록

- `npm run lint`: 통과
- `npm test`: API 51개 통과·DB E2E 1개 건너뜀, 웹 28개 통과
- `npm run build`: 소스·운영 의존성 수정 상태에서 contracts/API/web와 Next 23개 페이지 통과. 이후 개발 도구 취약점 잠금 파일 갱신 상태에서는 contracts/API 직접 빌드 통과, 웹 컴파일·TypeScript 통과 후 샌드박스의 페이지 워커 `spawn EPERM`으로 최종 정적 생성 재확인은 중단
- `npm audit` 및 `npm audit --omit=dev`: `qs`와 개발 도구 체인을 패치한 최종 잠금 파일에서 알려진 취약점 0건
- `docker compose --env-file .env.example -f infra/docker-compose.yml config --quiet`: 통과
- `C:\Program Files\Git\bin\bash.exe -n infra/backup.sh`: 통과
- 실제 Docker 이미지 빌드·기동: Docker Desktop Linux 엔진이 실행 중이지 않아 미검증
- 실제 PostgreSQL/MinIO/SMTP/브라우저 다계정 E2E: 격리 환경이 없어 미검증. 관련 DB E2E는 추가했으나 통과로 표시하지 않음
