# Android V1 · 선택적 게시 설계

2026-10-23 UTC · A-06 / M-07 · F-08~09. 기존 서버 정책을 보존한 개발 기준이며 P-03~04의 별도 사용자 확정으로 표현하지 않는다.

## 1. 흐름과 공개 경계

| 단계 | 사용자 경험 | 구현·권한 계약 |
| --- | --- | --- |
| 완료 | TODO 완료 성공 뒤 게시를 선택하거나 닫는다 | 완료는 `share=false`로 별도 저장. 게시 시트를 닫아도 완료 유지 |
| 다시 진입 | 완료 항목 메뉴의 기록 게시, 그룹의 루틴으로 게시 | 기존5탭 유지. 그룹은 완료 여부와 별개로 비어 있지 않으면 현행 서버 정책에 따라 게시 가능 |
| 내용 확인 | 원본 제목 → 선택적 사진 → 한마디 → 해시태그 → 공개 범위 → 게시 | 공통 NativeSheet의 본문 스크롤·IME·이탈 확인 계약 재사용. 한마디180자, 태그5개/각30자 |
| 공개 범위 | 전체 공개·팔로워·나만 보기를 명시적으로 표시 | 현행 게시 기본값 PUBLIC 유지. 원본 개인 TODO의 기본 PRIVATE와 별개이며 원본 공개 범위를 수정하지 않음 |
| 제출 | 피드에 게시하기를 누른다 | 기존 `POST /feed/posts`와 자체 세션·멱등 키 사용. todoId 또는 todoListId 중 하나와 caption/hashtags/visibility/선택 mediaId |
| 성공 | 확인된 게시 ID를 받은 뒤 닫고 관련 자료 갱신 | HTTP 성공이어도 게시 ID가 없으면 결과 불확실. 이전 계정·취소된 coroutine의 결과로 닫기/성공 처리를 하지 않음 |
| 완료 취소 | 게시 연결로 취소가 제한될 수 있음을 사전 안내 | 기존 서버의 활성 게시 연결 제한 유지. 게시물·미디어 자동 삭제나 제한 우회 없음 |

서버는 본인 원본/삭제 상태, 단일 TODO의 완료 여부, 그룹의 비어 있지 않음, 준비된 본인 미디어를 다시 확인한다. 게시 snapshot·미디어 소유권·파기/차단 정책과 API/schema는 변경하지 않는다. 새로운 게시 기본값·재게시 금지·연결 자동 해제 정책을 도입하지 않는다.

## 2. 상태와 복원

| 상태 | 화면·가능한 행동 | 보존·재시도 |
| --- | --- | --- |
| 작성 | 입력·사진·범위 변경, 닫기 시 변경 확인 | 계정 ID·원본 ID·단일/그룹 모드에 연결된 초안 |
| 사진 미완료 | 재시도·사진 제외. 게시 비활성 | 선택/촬영 URI·미디어 ID·pending을 폼과 함께 저장. 사진 bytes는 SavedState에 넣지 않음 |
| 게시 중 | 입력·사진·범위·닫기 잠금, 게시 중 표시 | 제출 시 본문 문자열·키·시각 고정. 연속 탭 차단 |
| timeout/5xx/409/전송 취소 | 입력 잠금, 게시 결과 확인만 명시적으로 가능 | 동일 본문·동일 키. 자동 전송 없음. 복원된 진행 중 요청도 이 상태로 시작 |
| 불확실한 요청이5분 경과/시계 역행 | 재전송 차단, 닫고 마이의 게시 기록 확인 안내 | 서버 미완료 멱등 키의 최소 보존 범위를 넘겨 새 게시를 만들지 않음. 정확한 성공 여부 자동 대조 API는 이번 범위 밖 |
| 확인된400/422 등 거부 | 입력 유지, 수정 가능 | 같은 본문은 기존 키, 수정한 제출은 새 키 |
| 401/403 | 재전송·수정 잠금, 로그인/권한 사유 표시 | 상태 복원 뒤에도 거부 유지. 로그인 상태를 확인한 뒤 다시 열기 |
| 불확실한 상태에서 닫기 | 이미 반영됐을 수 있고 닫아도 취소되지 않는다는 확인 | 서버 게시·완료 취소 요청을 보내지 않음. 닫은 초안을 영구 보관하는 정책은 추가하지 않음 |
| 계정/대상/모드 전환 | 이전 초안·사진·요청 상태 재사용 금지 | Saver에서 소유 범위를 직접 검증. 그룹 화면의 목록·시트도 계정/세션 범위로 재생성 |

토큰·쿠키·전체 원본 JSON은 게시 상태에 저장하지 않는다. 사진을 업로드한 뒤 게시에 실패해도 결과 확인은 기존 mediaId를 재사용한다. 업로드하지 않은 태그 입력은 제출 시 정규화해 추가하고, 잘못된 태그는 입력을 유지하며 전송을 막는다.
