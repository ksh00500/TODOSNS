# Android · 기능 구현 이후의 화면 완성도 작업

2026-10-25 (Asia/Seoul). 기준 브랜치 `codex/beta-core`.

사용자 요청에 따라 Google/Firebase·서명 키 등 사용자 제공이 필요한 항목은 보류하고, 현재 코드와 합성 데이터로 진행할 수 있는 화면·사용 흐름을 먼저 개선한다. 기존 Cloud Rhythm 디자인 기준과 5탭·서버 계약·초안/결과 미확인 보호를 유지한다. 기능 구현 완료와 디자인·제품 인수 완료를 구분한다.

사용자 후속 승인으로 기존 시각 규격에서 벗어나는 차분한 매거진 방향과 연하늘·연초록·연노랑을 적용한다. [Android 시각 기준](../../design-system/android-pastel-editorial.md)과 [파스텔 구현 결과](implementation-pastel.md)를 함께 따른다. 오늘·탐색·마이의 첫 시각 개선이며 아래 각 사용 흐름의 전체 검수를 대체하지 않는다.

| 순서 | 범위 | 완료 기준 | 상태 |
| --- | --- | --- | --- |
| UI-01 | 오늘·일정의 정보 위계 | 작은 진행 요약, 현재 실천 우선, 목록/추가 진입 구분, 긴 글·큰 글자·빈/모두 완료/오류에서 행동 접근 | 1차 구현·선별 검증 완료. 실제 범위는 [보고서](implementation-ui01.md) |
| UI-02 | 탐색·게시물·가져오기 | 사진/실천 제목 중심 카드, 가져오기 주 행동, 응원/댓글 보조 위계, 느린 사진/권한 변경/미확인 결과 표시 검수 | 사진 상태/재시도·원본 요약·일정 미리보기·진입점 복원 구현 및 로컬 선별 검증. [보고서](implementation-ui02.md). 실제 권한 변경·전체 사용 흐름 검수는 잔여 |
| UI-03 | 작성·편집·게시·공통 시트 | 필드/도움말/오류 간격, 사진 상태, 저장 중 표시, IME·닫기·초안 복원 검수 | 예정 |
| UI-04 | 챌린지·마이·기록 | 기간/내 상태·주 행동 구분, 기록·통계 밀도, 긴 콘텐츠·빈/오류 상태 검수 | 마이 시각1차 적용. 챌린지/기록·전체 사용 흐름 검수는 후속 |
| UI-05 | 핵심 순환 통합 검수 | 작성→완료→선택적 게시→다른 계정 가져오기→재완료, 화면 전환·뒤로가기·재시도 확인 | 예정. 가능한 로컬 합성 검증과 실제 기기 검증을 분리 |

각 묶음은 구현 후 360/390/430dp, 글자 200%, 해당 오류·빈 상태와 터치 영역을 검사하고 직접 확인한 캡처와 실행 결과를 남긴다. 전체 화면의 검증을 일부 화면의 통과로 대체하지 않는다. 새로운 정책이나 외부 에셋/폰트·라이브러리를 추가하지 않는다.

## 보류 항목

실제 Google/OAuth·FCM, 기존 업로드 키·서명 AAB·Play 설치, 운영 배포·도메인, 실기기 제공과 미정 제품/법률 정책은 [M-13의 B-01~07](implementation-m13.md)에 남긴다. 보류는 완료나 기능 제거를 뜻하지 않는다. 지금은 설정 제출을 요청하거나 Actions를 조사/재실행하지 않는다.
