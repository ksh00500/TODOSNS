# M-03 · 오늘 화면의 정보 위계와 조회 상태

2026-10-23 UTC · 구현 및 현재 Codex 검사 결과

검사 대상: `codex/beta-core@fa6d1e6fb978ca4908ad6dd0b513926b79d0865d`에 이번 Android 코드·시험·문서 변경을 더한 작업 트리. 기존 5탭·네이티브 시트·예정일 API를 유지한다. 서버·DB·workflow·manifest·의존성/lockfile 변경과 운영 배포는 없다.

## 1. 화면과 동작

| 상황·영역 | 구현한 동작 |
| --- | --- |
| 첫 화면 | 계정 날짜·인사 → 조회 상태 → 작은 진행 요약 → 지금 할 일 → 오늘 목록 헤더/추가 → 나머지 목록. 큰 원형 진행 표시를 줄이고 현재 실천의 완료 버튼을 주 행동으로 유지 |
| 첫 조회 중 | 불러오는 중 안내. 미확인 `0/0`, 빈 하루 또는 완료 축하를 표시하지 않음 |
| 확인된 빈 목록 | 빈 상태 안내와 목록 헤더의 `TODO 추가`를 주 행동으로 표시. 다른 추가 진입점을 중복 생성하지 않음 |
| 정상 목록 | 완료/전체·남은 수 표시. 지금 할 일은 미완료 중 실제 dueDate 시각, ID 순서로 선택. 응답 배열 순서·UTC offset 표기 차이에 의존하지 않음 |
| 재조회 | 기존 목록·수치를 유지하고 갱신 중 안내. 조회 중 완료·취소 및 항목 메뉴 잠금 |
| 일반 조회 실패·연결 오류 | 이전 자료가 있으면 목록·수치·마지막 목록 확인 시각 유지, 재시도 제공. 최초 실패나 이전 빈 목록의 갱신 실패를 정상 빈 상태로 표시하지 않음 |
| 조회 401/403 | 이전 비공개 항목·확인 수치·시각을 제거하고 오류 안내. 캐시된 자료로 완료/취소하지 않음 |
| 변경 중 | 낙관 상태는 `변경 확인 중`과 접근성 상태로 구분. 미확정 단말 시각을 실제 완료 시각으로 표시하거나 전체 완료를 축하하지 않음 |
| 완료 목록 | 색·취소선 외에 `완료` 텍스트와 서버 completedAt의 계정 현지 날짜/시간 표시. 기존 체크·메뉴·게시 동작 유지 |
| 그룹 | 지금 카드의 항목을 일반 목록에서 중복 표시하지 않되 그룹 집계에는 포함. 단독으로 지금 카드에 있는 그룹도 소속·완료 수 표시. 그룹 조회 실패는 안내와 재시도 제공, 기존 자료가 있으면 유지 |
| 계정·날짜 경계 | 계정/세션별 모델과 계정별 화면 상태 사용. 새 날짜·시간대 제목 아래 이전 query snapshot을 load effect 이전에도 숨김 |
| 복귀·자정 | 화면이 RESUMED가 되면 재조회하고 계정 시간대의 오늘 재계산. 화면이 열린 동안 자정과 최대 1분 간격의 기기 시각 재확인. 새 날짜여도 열린 TODO 폼의 기존 날짜·본문 유지 |

진행 수는 예정일 목록의 현재 완료 상태다. 실제 완료일별 기록을 구현했다고 표시하지 않는다. 현재 `GET /todos`의 `to`는 끝 포함(다음 현지 자정 - 1ms)이며 DST 23/25시간 날짜에도 기존 계약을 유지한다.

신규 Compose 시험은 loopback 합성 HTTP·합성 계정 컨텍스트·주입 시계를 사용한다. 실제 두 계정 로그인이나 기기 시계 변경 시험이 아니다.
