# Android V1 · 검수 시나리오와 구현 작업

문서 ID: AND-V1-QA-001 · v0.1 · 2026-10-23 (Asia/Seoul)

이 문서는 상세 설계에서 정의한 시험과 작업이다. 원래 초안 작성 당시에는 실행하지 않았다. 후속 구현의 실제 실행 범위는 [M-01](implementation-m01.md)·[M-02](implementation-m02.md)·[M-03](implementation-m03.md)·[M-04](implementation-m04.md) 보고서를 따르며, 전체 AT 시나리오의 통과를 의미하지 않는다. 이전 54개 Android unit 결과는 `887fdef`의 기준선이다.

## 4. 변경 단위의 완료 정의

1. 작업에 연결한 요구·화면·계약·권한 영향과 경계 조건을 확인한다.
2. 재발 가능성이 있는 행동을 검증하는 기존/새 시험을 실행한다. 구현을 그대로 따라 쓰는 형식적 검사는 피한다.
3. 변경 영역에 맞는 Debug/unit/lint와 API/Web 회귀 검사를 수행한다. 통과 후 근거 없이 같은 검사를 반복하지 않는다.
4. 실제 DB·스토리지·Compose 연결·실기기 검사가 필요한 항목의 실행 여부를 분리한다.
5. source SHA·시각·환경·명령·건수·failure/skip/unrun을 기록하고 기억을 갱신한다.
6. GitHub Actions 상태 조사·수동 재실행·결제 제안·CI 목적 커밋은 하지 않는다.
